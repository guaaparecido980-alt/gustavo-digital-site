# Prompts — A travessia (4 imagens + 3 clipes)

Gerados a partir de [roteiro.md](roteiro.md). Ordem obrigatoria: A -> B -> C -> D,
sempre anexando a imagem anterior no chat do ChatGPT e dizendo
"same world, same lighting, same lens - only the camera moved".

## Universo (v2 — rede, nao galeria)

Espaco digital escuro com um piso de malha wireframe dourada que se estende ate
o horizonte, nos de luz ambar espalhados, neblina escura e particulas. O portal
e um anel feito de linhas e nos de dados — nao um arco de concreto. No fim, a
camera emerge sobre a Terra a noite coberta pela malha de conexoes.

**Ouro sempre. Azul nunca.** Rede tech generica sai azul/ciano por padrao — por
isso o negativo `no blue` aparece em todos os prompts e nao pode ser removido.

## Preparo dos arquivos

O ChatGPT entrega 1536x1024 (3:2). Cortar para 16:9 antes de subir:

```bash
for f in a b c d; do ffmpeg -y -i "$f.png" -vf "crop=iw:iw*9/16" "$f-169.png"; done
```

Pontes reais — nao usar a imagem do ChatGPT como start do clipe seguinte:

```bash
ffmpeg -sseof -0.04 -i c1.mp4 -frames:v 1 ponte-b.png
ffmpeg -sseof -0.04 -i c2.mp4 -frames:v 1 ponte-c.png
```

## Criterio de aprovacao (antes de gastar credito no proximo clipe)

- A camera anda em linha reta e o horizonte nao inclina.
- Nada nasce, some ou se deforma no meio do movimento.
- O ouro nao virou azul, ciano nem laranja saturado.
- Nenhuma letra, numero ou HUD aparece em lugar nenhum.
- O ultimo quadro do clipe bate com a imagem de destino.
